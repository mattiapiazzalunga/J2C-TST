# J2C-TST

Code, notebooks, and corpora required to reproduce the J2C-TST pipeline, from
data collection and cleaning to baseline training and evaluation.

## Structure and execution order

1. `1-generating_english_corpus/`: generates or updates the raw English corpus.
2. `2-raw_data/`: contains the raw EN and IT corpora.
3. `3-cleaning/`: cleans the corpora and produces the official CSV files.
4. `4-official_corpora/`: contains the final datasets used in the experiments.
5. `5-baselines/`: runs few-shot prompting, LoRA, and prefix-tuning for EN and IT.
6. `6-evaluation/`: trains the style classifiers and computes the metrics.
7. `7-datasets_analysis/`: analyzes corpus composition and characteristics.
8. `8-results_analysis/`: compares results by social platform.

Each stage with specific dependencies includes its own `requirements.txt` and,
when necessary, a more detailed README. To reproduce the experiments, open and
run the notebooks for the desired language in the order shown above. The
training and evaluation notebooks are configured for Linux, CUDA/BF16, and a
GPU with approximately 48 GB of memory; gated model access requires a personal
Hugging Face token.

## Quick start

```bash
cd 5-baselines
pip install -r requirements.txt
# Open J2C-TST-EN/run_baselines_EN.ipynb or
# J2C-TST-IT/run_baselines_IT.ipynb

cd ../6-evaluation
pip install -r requirements.txt
# Open J2C-TST-EN/run_evaluation_EN.ipynb or
# J2C-TST-IT/run_evaluation_IT.ipynb
```

After evaluation, run the EN/IT notebooks in directories 7 and 8 to regenerate
the analysis tables and figures.

For FlashAttention and BELA, follow the README files in their respective
directories. The evaluation stage prepares BELA through `setup_bela.py` and
downloads its assets separately; they require approximately 21 GiB.

## Excluded files

The repository does not include models, adapters, checkpoints, caches, virtual
environments, logs, predictions, or generated results. Outputs already embedded
in the notebooks are retained. All excluded artifacts can be regenerated by
running the pipeline.

Note: `2-raw_data/IT/raw_dataset_IT.csv` exceeds GitHub's standard 100 MB
per-file limit; publishing it requires Git LFS or external storage. The official
corpus used directly for training remains below that limit.
