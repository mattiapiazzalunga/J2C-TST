# English corpus generator

The entry point is [`generate_english_corpus.ipynb`](generate_english_corpus.ipynb). It produces:

```text
../2-raw_data/EN/raw_dataset_EN.csv
```

with exactly these columns:

```text
title,author,journalistic_style,link_to_journalistic,conversational_style,link_to_conversational,social_network,license
```

## Run

1. Open `generate_english_corpus.ipynb` in Jupyter.
2. Run the dependency cell.
3. Review `max_pages_per_source` in the configuration cell.
4. Run the pipeline cell.

Interrupting the kernel is safe. Accepted rows and the current social-feed page are stored in `state/english_corpus_checkpoint.sqlite3`. The next run resumes the uncompleted page. `../2-raw_data/EN/raw_dataset_EN.csv` is replaced atomically from the checkpoint, including after an interrupt.

Connection timeouts, connection errors, interrupted/chunked responses, and
response-decoding transport failures wait with bounded exponential backoff
until a request succeeds or the operator interrupts. Repeated remote-server or
temporary identity-verification failures pause only the affected source while
preserving its cursor.

## Precision contract

- A social post is considered only when it is an original, top-level post from a pinned publisher identity. Mastodon must explicitly mark it as English. Bluesky must mark it as English unless the verified Global Voices account omits `langs`; an explicit non-English value is always rejected.
- Alignment uses only a Bluesky link facet/external embed or a Mastodon anchor/card, followed by HTTP redirects and an exact configured English article path.
- No title comparison, fuzzy matching, semantic similarity, embedding, or keyword heuristic is used.
- The downloaded article must expose exactly one canonical URL, title container, and body container.
- `author` is selected only from publisher-specific author-credit structures. Global Voices retains only contributors whose exact role is `Written … by`; translators are not authors. Multiple written authors are preserved in DOM order with newline boundaries.
- The effective and canonical URLs must identify the same accepted publisher path.
- Global Voices articles must use the English single-post template, exact dated canonical path, Global Voices site marker, internal author profile and stable entry container.
- Global Voices announcements, `Guest Contributor` pages, and pages that explicitly identify partner, republished or content-sharing material are rejected.
- Related-news widgets, image widgets and captions, media, factboxes, notes, social embeds, and italic special-coverage preambles are excluded by DOM structure.
- A Global Voices page is rejected when a promotional call to action is embedded as an unwrapped article paragraph and therefore cannot be removed structurally.
- Global Voices partner/republication notices are checked in every body block type that the text projector could otherwise retain.
- Unsupported visible body blocks cause rejection.
- The text projection preserves text-node content and uses only DOM block boundaries for line breaks. It performs no linguistic cleaning or Unicode normalization.
- `license` is assigned deterministically as `CC BY 3.0` for Global Voices.
- A row is inserted only after every validation succeeds.
